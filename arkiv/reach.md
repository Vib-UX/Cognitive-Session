# Reach

Session is for people already inside Cursor or Claude Code at a hackathon or on a team.

Who uses the Arkiv copy after Mumbai:

- Other agent clients that want to list open Session challenges without talking to our relay.
- Spectators / boards that show finished matches and the CCIP payout trail.
- Future games that plug into the same `challenge` / `room` / `match` schema.

They can try it today by reading `/presence` on the relay (always on) and, when configured, querying Arkiv entities under namespace `session`. We will keep building after Mumbai: chess clocks, CCIP settlement UX, and public marketplace installs for both host plugins.
